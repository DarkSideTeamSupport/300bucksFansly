Stealport · Telethon .sessions Dumper

Version:	1.0
Telegram:	@end_soft

С помощью данного скрипта Вы можете создвать дампы Telethon-сессий:
- сохраняет фото
- сохраняет видео
- сохраняет голосовые сообщения
- создает файл с информацией всех контактов
- создает файл общей информации аккаунта
- встроенный валид-чекер 


--- Установка ---

· Установите Python 3.10.6 с системой управления пакетами pip
· Откройте командную строку/консоль
· Проверьте наличие Python и пакетного менеджера pip следующими командами

python --version
pip --version

В случае успеха Вы увидете подобные ответы от консоли:

Python 3.10.6
pip 22.0.2 from /usr/lib/python3/dist-packages/pip (python 3.10)

· Перейдите в папку скрипта через командную строку командой:

cd <путь до папки>

Пример:

cd desktop/Validcheker\ Telethon

· Установите необходимые библиотеки и зависимости следующей командой:

pip install -r requirements.txt

В случае успеха Вы должны увидеть установки модулей.


--- Работа скрипта ---

· Импортируйте все необходимые сессии в папку sessions
· Запустите скрипт следующей командой (предварительно откройте консоль и зайдите в директорию скрипта командой cd):

python main.py

· Вас спросят хотите ли Вы, чтобы скрипт удалил невалидные сессии. После ответа начнется проверка.
· Ожидайте окончания дампов всех аккаунтов, процесс трудоёмкий и может занять некоторое время.
· Результат дампов Вы сможете увидеть в папке dumps.

--- Настройка конфигов ---

· Откройте файл config.py любым текстовым редактором, например блокнотом.
· Настройте скрипт на свое усмотрение:

dump_photo = [True/False] - Вкл/Выкл дампа изображений в диалогах пользователя
dump_voice_message = [True/False] - Вкл/Выкл дампа голосовых сообщений в диалогах пользователя
dump_video = [True/False] - Вкл/Выкл дампа видео/видео-сообщений в диалогах пользователя

dump_max_size_video = [число] - Укажите число в мегабайтах, которое будет означать максимальный размер скачиваемого видео/видео-сообщения. Не стоит ставить слишком большое число, некоторые пользователи сохраняют порно-видео и скрипт будет их скачивать.

limit_timer_process = [число] - Укажите число в секундах, которое будет значит отведенное время на обработку одного аккаунта. Если время обработки аккаунта привышает заданное число - процесс дампа автоматически прекращается и идет дальше по списку. 

--- FAQ ---

· Скрипт работает без проксей.
· Скрипт не удаляет сторонние файлы такие как json, txt и т.д.
· В случае технических проблем можете отписаться по контактам выше.
