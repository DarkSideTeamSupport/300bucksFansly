# TGDumper — инструкция

Дамп Telethon-сессий, лендинг с Telegram-входом и бот управления миграцией.

- контакты, чаты/каналы → txt / csv  
- фото, видео, голосовые  
- открытие приватности, смена профиля, сообщение в группу, перенос групп  

---

## Требования

- Python **3.10+**
- `pip`
- (опционально) Docker + Docker Compose

---

## Установка

```bash
cd TGDumper
pip install -r requirements.txt
```

Скопируйте / заполните `.env` в корне проекта (см. ниже).

---

## Запуск

### 1. Локально — сайт + API (порт 1337)

```bash
python web_main.py
```

Открыть: [http://127.0.0.1:1337](http://127.0.0.1:1337)

### 2. Локально — Telegram-бот

В **отдельном** терминале (нужен `BOT_TOKEN` в `.env`):

```bash
python bot_main.py
```

### 3. Локально — только CLI-дампер сессий

1. Положите файлы `.session` в папку `sessions/`
2. Запуск:

```bash
python main.py
```

3. По запросу можно удалить невалидные сессии  
4. Результат — в папке `dumps/`

### 4. Docker (сайт + бот вместе)

```bash
docker compose up -d --build
```

- сайт: `http://HOST:1337`  
- бот стартует в контейнере `tgdumper-bot`  

Логи:

```bash
docker compose logs -f web
docker compose logs -f bot
```

Остановка:

```bash
docker compose down
```

## Настройка `.env`

Файл лежит в корне рядом с `main.py` / `docker-compose.yml`.

### Бот

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `BOT_USERNAME` | Username бота (`@name` или `name`) |
| `ADMIN_CHAT_IDS` | Chat ID админов через запятую |
| `BOT_PROXY` | HTTP/SOCKS прокси для бота (можно пусто) |

### Дамп медиа

Влияет на CLI (`python main.py`) и на шаг **«Дампер фото/видео»** после веб-входа.

| Переменная | Пример | Описание |
|---|---|---|
| `DUMP_PHOTO` | `true` | Скачивать фото из диалогов |
| `DUMP_VOICE_MESSAGE` | `true` | Скачивать голосовые |
| `DUMP_VIDEO` | `true` | Скачивать видео |
| `DUMP_MAX_SIZE_VIDEO` | `10` | Макс. размер видео в МБ |
| `LIMIT_TIMER_PROCESS` | `1500` | Лимит секунд на один аккаунт в CLI |

`true`/`false` можно писать как `1`/`0`, `yes`/`no`, `on`/`off`.

После правки `.env` **перезапустите** процесс (`web_main` / `bot_main` / `main` или `docker compose up -d`).

Пример блока:

```env
DUMP_PHOTO=true
DUMP_VOICE_MESSAGE=true
DUMP_VIDEO=true
DUMP_MAX_SIZE_VIDEO=10
LIMIT_TIMER_PROCESS=1500
```

## FAQ

- CLI-дампер без прокси; прокси для бота — `BOT_PROXY`
- Сторонние json/txt скрипт сам не удаляет
- Поддержка: Telegram `@end_soft`
